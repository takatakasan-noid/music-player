# マイ音楽プレイヤー（Google Drive版）

自分で録音した音楽を、Google Driveに保存したままブラウザ（PC・iPhoneどちらも）で再生できるサイトです。音源の実体はGoogle Drive上だけに置かれ、このサイト自体には保存されません。ログインしたご自身のGoogleアカウントでしかアクセスできません。

## 初回セットアップ（1回だけ）

### ① `js/config.js` に値を入れる

```js
const CONFIG = {
  CLIENT_ID: "xxxx.apps.googleusercontent.com", // OAuthクライアントID
  FOLDER_ID: "xxxxxxxxxxxxxxxxxxxx",             // 音源用DriveフォルダのID
};
```

- `CLIENT_ID` … Google Cloud Console の「APIとサービス」→「認証情報」で作成したOAuthクライアントID
- `FOLDER_ID` … 音源を入れるGoogle DriveフォルダのURL `https://drive.google.com/drive/folders/【ここ】` の部分

### ② GitHub Pagesで公開する

```bash
cd "音楽プレイヤー"
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

その後 GitHub のリポジトリ設定 → Pages で `main` ブランチを公開に設定すると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになります。

このURLを Google Cloud Console のOAuthクライアント設定「承認済みのJavaScript生成元」に追加するのを忘れずに。

## 使い方

1. サイトを開き、「🔐 Googleでログイン」をクリック
2. 初回は「このアプリは確認されていません」という警告が出ることがあります。これは個人利用のアプリだからで問題ありません。「詳細」→「（アプリ名）に移動」で進めます
3. ログインすると、指定したDriveフォルダ内の音源が一覧表示されます

## 曲の追加方法

以下のどちらでも自動的に反映されます。

- **どこからでも**: Google Driveアプリ（PC・iPhoneどちらも）で、指定フォルダに音源ファイルを入れる
- **サイトから**: ログイン後、「＋ 曲を追加」またはドラッグ&ドロップでアップロード（アップロード先は指定のDriveフォルダ）

次にサイトを開いたとき（またはログインし直したとき）に一覧へ反映されます。

## プレイリスト

- 左側の「＋ 新規プレイリスト」から複数のプレイリストを作成できる
- 「すべての曲」表示で、各曲の右側のプルダウンからプレイリストに追加できる
- プレイリスト表示中は、曲をドラッグして並び順を変更したり、「－」ボタンで削除できる（音源ファイル自体は削除されない）
- プレイリスト名の変更・削除は、サイドバーの項目にカーソルを合わせると出る ✎ / 🗑 ボタンから行う

プレイリスト情報は、Driveの同じフォルダ内に `playlists.json` として自動保存されます。

## 繰り返し再生

再生バーの🔁ボタンをクリックすると、以下の順で繰り返しモードが切り替わります。

- なし（1周したら停止）
- 🔁 全曲繰り返し
- 🔂 1曲だけ繰り返し

## 著作権・プライバシーについて

このサイトは「リンクを知っていれば誰でも聴ける」公開方式ではなく、Googleアカウントでのログインを必須にしています。ログインしたご自身しか音源にアクセスできないため、個人の録音物を個人で聴く用途として問題ありません。ただし、他者の著作物（市販曲・ラジオ番組など）を録音したものを扱う場合は、共有範囲を広げないよう注意してください。

## ローカルでのテスト方法

```bash
cd "音楽プレイヤー"
python3 -m http.server 8000
```

`http://localhost:8000` を開いてテストできます（`CLIENT_ID`の「承認済みのJavaScript生成元」に `http://localhost:8000` を追加しておく必要があります）。
